# 区域原始格点绘图与色标

2026-11-04

原先区域视图裁切全球预渲染图，沿用整幅产品色标；较小的区域差异容易集中在相似颜色内。旧图例还将小数取整为重复刻度。

现在对含 region 的地图，从 `/api/seasonal/region-grid` 读取选定文件、变量、月份和包围框内的全部原始格点。前端按真实格点单元绘制色块，并在有足够屏幕空间时标注数值；不会只用中心附近九个点填充整块区域。默认区域色标使用所选全部月份的共同范围，距平以零对称；概率仍使用 0–100%。可切换产品统一色标。图例与色块使用同一映射，并保留小数。

单元几何按原始中心坐标和网格间距计算，单元边界裁到请求包围框。缺测不作为零值；常量场保持相同颜色并说明数值相同；没有范围内格点时不使用外部格点。区域摘要显示当月有效格点数和原始最小/最大值，不计算或冒充城市面积平均。原单点曲线继续保留。区域格点正常加载后隐藏旧的九圆点标记，避免与新的数值分布图重复。

新接口复用既有原始格点服务的单位转换、时次匹配、文件大小/变量规模限制、每次数据库权限检查、目录边界检查、串行科学文件读取和 LRU 缓存。返回最多 5000 个区域格点及 36 个时次，较大区域提示缩小范围，页面保留原产品图。缓存键含包围框。没有读取图片颜色估算数据，也没有训练或运行新模型。

验证：8 项原始格点服务测试、9 项相关 Vue 工具测试通过；Vue 构建通过。真实 NOAA 原始文件生成的 7×7 京津冀示例格点用于浏览器验证，覆盖数值/颜色、固定跨月色标、小数刻度、常量场、响应身份校验和失败回退。实际本机接口匿名请求返回 401，使用有效本机身份读取返回 200、7×7 格点、3 个月份，单位 mm/day。

浏览器脚本：`work\seasonal-sources\check_regional_field.mjs`。截图：同目录 `seasonal-regional-field.png`。无需重新解析已有文件；将地图收起后再展开即可使用当前渲染逻辑。
