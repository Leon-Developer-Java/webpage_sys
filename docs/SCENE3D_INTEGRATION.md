# Scene3D 页面接入

平台新增 `/scene3d` 路由和三维场景导航，延续业务用户权限限制。聊天结果通过校验消息来源和 run_id 后打开同一服务器任务。

`VITE_SCENE3D_BASE` 为经过身份验证的网关地址，开发默认 `http://127.0.0.1:8013`。页面使用现有 authedFetch 获取业务数据，Cesium 运行资源由 Scene3D 服务提供。环境变量示例见 `.env.example`。

保留原地形、杆塔、导线、WebGPU 风场粒子、配色和高度分层。左键平移，右键或中键旋转，滚轮缩放。增加 GPU 设备初始化重试、设备丢失后的恢复及错误提示，不使用替代风场显示方案。

本次集成保留上游 WRF UI 2.2.9、覆冰地图入口、认证处理及时间轴更新。单元测试和生产构建均已验证；未在本次上传过程中启动平台或服务器计算服务。
