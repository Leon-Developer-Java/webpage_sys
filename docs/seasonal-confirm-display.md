# 季节降水先选择、再确认展示

2026-11-04

数据总览的季节降水入口不再自动展示最近产品。已下载产品、起报批次、有效时次、时间范围和文件列表用于准备待确认选择。左侧展示实际文件产品、批次、时次，用户点击“确认展示”后，才挂载降水图层并加载图像。

修改条件或选择另一文件时，清除对应展示，地图提示先完成选择再确认，右侧元数据和时间轴也不沿用旧文件。筛选无结果、时间范围未填写完整、有效时次无效或数据读取失败时无法确认，不回退到最新产品。

确认成功后，下方时间轴与播放控件直接切帧；左侧有效时次同步当前画面。再次修改左侧时次则作为新选择，等待确认。不透明度偏好继续保留。在线产品下载依然使用“下载所选”，解析完成后在已下载目录选择并确认展示。

入口收到明确的文件/变量/有效时次参数时，保留这些标识作为待确认项，不直接出图。双屏/四屏对焦某一屏修改选择时，只清除该屏；其他已确认屏幕保留。并发请求用既有请求序号隔离，旧的元数据或确认响应不能覆盖后来的选择。

主要实现位于 `src/views/Overview.vue`，待确认资源与已展示资源分开。季节图层只有已展示资源存在时挂载，避免未确认时 GribLayer 自行加载最新图像。其他数据源沿用原流程，共享 WRF UI 制品未修改。

验证：22 项相关工具测试、Vue 构建通过。浏览器使用真实 Vue 页面与 NOAA 图像，模拟认证和数据 API，验证确认前没有降水图片请求、产品/批次/时间/文件选择、精确时次确认、时间筛选、空结果、读取失败重试、过期请求、入口参数、双屏独立确认和不透明度保留。没有大模型调用。

脚本：`work\seasonal-sources\check_seasonal_confirm.mjs`。截图：同目录 `seasonal-confirm-before.png`、`seasonal-confirm-after.png`。构建日志：`seasonal-confirm-build.log`。
