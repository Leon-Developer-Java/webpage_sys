# WRF shared UI

The workbench owns this source package. Both Vue and React consume the same immutable tarball, built with `node scripts/build-wrf-ui.mjs --update-lock`. Install this package's locked dependencies before building. Consumers retain their own npm/pnpm locks. Never publish different source under the same version in a deployed release.

`registerWrfElements()` registers `wrf-config-editor`, `wrf-domain-map`, `wrf-run-viewer`, and `wrf-result-viewer`. Complex inputs are DOM properties. Native events expose a direct `event.detail` object, without a Vue array wrapper.

- Editor: `config`, `options`, `preview`, `previewPending`, `previewError`, `disabled`, `submitDisabled` (only execution button), `readOnly`, `hideSubmit`, `hostMode`, `showHeader`, `editorKey` (stable draft/task identity, never its version). Emits `config-change {config}`, `preview-request {config,edit?,requestId}`, `action {action}`, `validation-change {valid,errors}`.
- Map: `config`, `preview`, `disabled`, `readOnly`. Emits `preview-request {config,edit?,requestId}`.
- Run: `task`, `logs`, `hostMode`, `allowedActions`. Agent mode allows only refresh/result by default. Emits `action {action}`. During computation, `task.runtime.current_stage`, `current_stage_status`, `current_model_time` (ISO UTC), and `model_progress` (0..100 from observed model time) supply actual progress. Missing model progress displays stage text rather than the task's coarse workflow percentage; terminal/output workflow stages take precedence over a previous simulation stage. Failure alerts show a factual Chinese summary; only `runtime.remote_wrf_succeeded === true` states that remote computation completed. Recognized output-validation/namelist-read signatures do not change stored failures. Technical details are collapsed, credential-redacted and limited to 12000 characters; unknown errors do not invent a cause.
- Result: `product` (`meta_json` or sanitized `domains`), `assetResponses`. Emits `asset-request {path,requestId}`. The host supplies `assetResponses[requestId]={url,error?}` and owns Blob URL cleanup.

Components have no business network calls, token storage, task submission, or environment repair. Public OSM tiles are optional visual context; server-validated projected boundaries remain authoritative. API authentication, sequencing, draft persistence, idempotency, and native ASK remain in host adapters.

Numeric geometry, runtime and non-enumerated physics fields keep incomplete or invalid raw text in component-only buffers. They emit `validation-change {valid:boolean,errors:string[]}` synchronously; hosts must block every save/plan/execute entry while invalid, including keyboard and automatic paths. Valid finite values emit on `input`, without requiring blur. Same-draft config polling and preview replies preserve buffers; changing `editorKey` resets them. Undo cancels unfinished numeric input, and deleting a subtree removes only its own buffers. Hosts must invalidate pending previews when geometry changes and apply responses only when both the request sequence and requested geometry still match. Preserve runtime edits while applying canonical preview geometry; a late response must never replace newer coordinates or grid dimensions.

Cumulus is edited for the selected domain. `config.ui_cumulus_overrides` maps stable node keys to explicit values; absent keys follow the current service resolution rule. `calculationRequest` removes this editor-only field, omits cumulus when every domain is automatic, or resolves mixed automatic/explicit values into the existing complete `cu_physics_by_domain` array. Other explicit domain choices survive a reset, geometry edits and renumbering; new domains are automatic. Loaded complete arrays remain explicit. A deliberate cumulus edit clears the conflicting same-name advanced namelist override; merely loading a request does not resolve conflicts. Domain removal lists the actual removed subtree and supports the existing undo action.

Build with Node 24.14.1 / npm 11.11.0 and the package lock. Vue 3.5.38 is bundled and pinned; the Vue host must use this version to avoid Custom Elements internal patch API drift. React hosts should exclude this already-built package from Vite optimizeDeps. The canonical release lock records source, bundle and tarball hashes, and both consumer locks must reference that same integrity. Never deploy a changed tarball under an existing version.

The release builder uses `.artifacts/wrf-ui/<version>/package/dist` and a version-specific npm cache by default. Set `WRF_UI_NPM_CACHE` to a task-owned temporary directory for release validation, with guaranteed teardown. It preserves previous package dist and validation caches; application validation builds should also choose an isolated output directory.

Version 2.1.1 uses the workbench's shared WebGL2 projection engine for configuration and results. Display projection defaults to equirectangular and supports Mercator, sinusoidal, Robinson, Lambert, orthographic and both polar views. Display projection never changes the WRF calculation request. The main site map wraps the same source and injects its authenticated frame loader; components only load public tiles or host-supplied Blob URLs. Published EPSG:3857 raster coordinates remain Mercator when sampled into any display projection.

The document root's dark class/data-theme or an explicit theme property controls component surfaces and controls. The framework retains ownership of map appearance: base-map tiles are sampled without recoloring in both themes; its existing ocean, graticule and optional boundary styling is preserved. WRF never changes global theme or map preferences. Meteorological raster colors are never inverted. Results offer native units and common display units (T2 K to Celsius; PSFC Pa to hPa), with finite, bounded numeric labels. Unit conversion does not modify source data, published metadata or palette. Color scales use the actual published palette; absent metadata does not generate an invented palette. This is metadata consistency, not a claim of compliance with a universal meteorological color standard. Asset requests dispatch in a microtask so synchronous host cache responses cannot re-enter Custom Element mounting; validation events remain synchronous.

Offline global outline data comes from the workbench's existing Natural Earth 1:110m coastline and country-boundary datasets (public-domain cartographic context). It never substitutes for projected simulation boundaries.
